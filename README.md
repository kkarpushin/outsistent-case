# Outsistent × AI-Ковчег: от Instagram до заявок за один день

Живой кейс курса [AI-Ковчег](https://kovcheg.ai). Команда агентов Claude Code за один рабочий день, 26 октября 2026 года, провела полный цикл для бухгалтерской компании **Outsistent** («Аутсістент», Карина Замкова, Запоріжжя / онлайн по Україні):

1. **ДНК бизнеса** — интервьюер ответил на вопросы интервью сам, по всем постам двух Instagram, страницам сайта и упоминаниям в сети, без вопросов клиенту.
2. **Deep Research** — рынок, целевая аудитория, конкуренты, плюс проверка 31 ключевого вывода по первоисточникам.
3. **GAP-анализ и маркетинговые исследования** — три концепта продукта, решение и маркетинговый план.
4. **Бренд** — бренд-бук, снятый с действующего сайта. Цвета и логотип не менялись.
5. **Лендинг и сайт** — 9 страниц на Next.js. Сцены с маленькими бухгалтерами сгенерированы в Higgsfield.
6. **Рекламные креативы** — 12 штук, статика и видео.
7. **Тест рекламы в Meta** — запущен и в тот же день остановлен.
8. **CRM по фреймворку Ковчега** — AI-интервьюер, агент-отчётчик, панель для Карины и страница статистики.

**Результат онлайн:** https://karina.kovcheg.ai (лендинг для рекламы — [/ochyma-banku/](https://karina.kovcheg.ai/ochyma-banku/)).

**Живой план работ со статусами** — [`plan/plan.html`](plan/plan.html). Страницы результатов этапов лежат в [`plan/reports/`](plan/reports/). Это самодостаточные HTML-файлы: скачайте и откройте в браузере.

## Как это сделано

Агенты Claude Code со скиллами курса:
- **plan-artifact** — живой план и страницы результатов;
- **kovcheg-deep-research** — ДНК, исследования, GAP, маркетинг;
- **site-za-vecher** и **taste-skill** — сайт;
- **higgsfield-generate** — сцены и видео;
- **creative-ads** и **ad-spy** — креативы и разведка рекламы конкурентов;
- **meta-ads-pro** — запуск теста.

Исследования и проверки шли параллельно: по агенту на тему.

CRM построена по «9 слоям агентской системы» из урока 07 (подробно в [`crm/SYSTEM.md`](crm/SYSTEM.md)):
1. Клиент отправляет анкету.
2. AI-интервьюер в чате задаёт 4–6 вопросов.
3. Агент-отчётчик пишет бриф с приоритетом.
4. Карина ведёт заявку в панели.

Если Claude недоступен, интервью идёт по заготовленным вопросам, а бриф ждёт в очереди.

## Запуск сайта

```bash
cd site
npm ci
npm run build   # статика в site/out
```

Сервер CRM: `python3 crm/leads_api.py --host 127.0.0.1 --port 3240`. Пароль панели он создаёт сам в `crm/.crm-password`. Ключи (Claude, Meta, Telegram) читает из файлов вне репозитория.

## Чего здесь нет и почему

- **Секретов:** токенов, паролей, ключей. Перед публикацией все файлы проверены по шаблонам ключей и сравнением со значениями из локальных хранилищ секретов.
- **Заявок клиентов:** база `crm/leads.db` не публикуется.
- **Сырых выгрузок:** посты Instagram, копии страниц сайтов (на старом сайте в адресах страниц формы вопросов видны имена людей), копии сторонних статей и выдачи поиска, сырые данные Библиотеки рекламы. В отчётах остались ссылки на источники.
- **Чужих материалов:** референсы дизайна, которые прислал заказчик, и CSS старого сайта.

## Оговорки

- Цены (экспресс-проверка 4 000 грн, аудит от 20 000 грн), срок «3 робочі дні» и время ответа — значения, которыми заполнены пробелы на сайте. Клиент их пока не подтвердил.
