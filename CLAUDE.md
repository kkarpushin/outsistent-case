# Outsistent · Карина Замкова

Проект: ДНК, исследования, лендинг и сайт, реклама и CRM для Outsistent («Аутсістент», бухгалтерія і перевірки ризиків для власників ФОП і ТОВ). План работ — `plan/plan.json`, живая страница плана — `artifact_url` в нём (скилл plan-artifact). Результат каждого этапа публикуется отдельной страницей (`plan/reports/`) со ссылкой из плана.

Бренд не меняем: логотип и цвета Outsistent остаются те же (решение заказчика). Бренд-бук — `brand/brandbook.md`, токены — `brand/tokens.css`, стиль сайта — `DESIGN.md`.

## Правила сайта

Они важнее правил любых скиллов:

- Сайт — проект в папке site/ на Next.js, React, TypeScript и Tailwind CSS со статической выгрузкой (output: 'export'): при сборке страница становится готовым HTML, и текст сразу видят Google и ИИ-поисковики.
- В next.config — output: 'export' и images: { unoptimized: true }; cacheComponents и partialPrefetching выключи: со статической выгрузкой сборка с ними падает.
- Готовые компоненты, библиотеки и чужие промпты — можно: shadcn/ui, 21st.dev, React Bits, Motion, GSAP, Lenis, Three.js, иконки Lucide или Phosphor. Промпт или компонент написан под Vite или «просто React» — перенеси его в наш проект: компоненты те же.
- Картинки — в site/public/images/, видео — в site/public/video/. Публикуем только собранную папку site/out/: её делает команда npm run build.
- Язык сайта: украинский. Шрифты только с кириллицей, включая буквы і, ї, є, ґ. Подключаешь шрифт через next/font — добавь набор cyrillic.
- Типографика по нормам языка: тире «—» между словами, кавычки «ёлочки».
- DESIGN.md в корне проекта — наш стиль: цвета, шрифты, отступы и скругления бери из него. Он важнее референсов и стиля скилла. Заведи их переменными темы Tailwind (@theme), а не вписывай в каждый блок.
- Тексты оффера не переписывай: источник текста — landing/prototype.md. Сокращение можешь предложить в ответе, но в файле оставь текст прототипа.
- Не выдумывай цифры, отзывы, имена клиентов, логотипы и сертификаты. Где данных нет, ставь заметную пометку {ЗАПОЛНИТЬ}.
- Цитаты из research/ — слова людей с форумов, а не отзывы клиентов. Отзывами на сайте их не делай.
- Фото бери из site/public/images/. Где фото нет, оставь блок с подписью «Фото: что должно быть, размер». Картинки из генератора — иллюстрации, людей из генератора не выдавать за клиентов и сотрудников.
- Движение: не больше одной главной сцены и отклики на действия. Появление при прокрутке — коротко (до секунды), один раз и без прыжков. При prefers-reduced-motion страница стоит на месте.
- Прежде чем сказать «готово», посмотри сайт на ширине 375 и 1440 px. Перед публикацией собери его (npm run build): сборка должна пройти без ошибок.
- Файлы из research/ в папку site/ не копируй.
- Нельзя обещать «банк не заблокує» и «без штрафів», называть результат «аудиторським висновком», писать, что лимит 1 млн касается всех ФОП (только новых и «сплячих»). Подробно — research/synthesis/for-landing.md.
- Отвечай по-русски.
